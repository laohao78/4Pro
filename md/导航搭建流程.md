# 导航搭建流程

从零搭建这辆车的自主导航，按顺序一步步来。

## 1. Livox Mid360 雷达驱动

Mid360 通过网口连接，需手动配置 IP 后编译 SDK + ROS 驱动。

详见 [mid360.md](mid360.md)。

**关键**：FAST_LIO 需要 `xfer_format=1`（CustomMsg，含逐点时间戳/tag/线号），不能用 PointCloud2。

```sh
roslaunch livox_ros_driver2 msg_MID360.launch
# 验证: rostopic type /livox/lidar → livox_ros_driver2/CustomMsg
```

## 2. RealSense D435i 相机驱动

USB 连接，librealsense2 SDK + realsense-ros wrapper。

详见 [d435i.md](d435i.md)。

视觉 SLAM（ORB-SLAM3 / VINS-Fusion）只用红外双目 + IMU，RGB 未使用。

## 3. FAST-LIO 里程计

LiDAR+IMU 紧耦合，输出 odom→livox_frame 的 TF 和 PointCloud2 点云。

详见 [fast-lio.md](fast-lio.md)。

源码改动：`camera_init→odom`、`body→livox_frame`，不再需要 tf_relay 转发。

```sh
roslaunch fast_lio mapping_mid360.launch rviz:=false
```

## 4. 导航依赖

```sh
sudo apt install ros-noetic-move-base ros-noetic-map-server ros-noetic-global-planner \
  ros-noetic-teb-local-planner ros-noetic-pointcloud-to-laserscan \
  ros-noetic-pcl-ros ros-noetic-costmap-2d ros-noetic-slam-toolbox ros-noetic-amcl
```

| 包 | 作用 |
|----|------|
| move-base | 导航框架，调度全局/局部规划 + 代价地图 |
| map-server | 加载 .pgm+.yaml 静态栅格地图 |
| global-planner | A*/Dijkstra 全局路径 |
| teb-local-planner | TEB 局部轨迹优化 |
| pointcloud-to-laserscan | 3D 点云 → 2D /scan |
| costmap-2d | 代价地图 |
| slam-toolbox | 在线栅格建图 + 定位 |
| amcl | 蒙特卡洛定位 |

## 5. TF 树搭建

### 实车测量

| 变换 | x | y | z | 说明 |
|------|---|---|---|------|
| livox_frame → base_link | +0.13 | 0 | -0.15 | 雷达在底盘前方 13cm、上方 15cm |
| base_link → base_footprint | 0 | 0 | -0.03 | 底盘中心到地面投影 |

### TF 结构

```
map ──(slam/定位)──▶ odom ──(FAST_LIO)──▶ livox_frame
                                               │  (+0.13, 0, -0.15)
                                               ▼
                                          base_link
                                               │  (0, 0, -0.03)
                                               ▼
                                          base_footprint
```

静态 TF 在各 launch 里用 `static_transform_publisher` 发布。FAST_LIO 源码已改为直接输出 `odom → livox_frame`。

详见 [TF架构.md](TF架构.md)。

## 6. 栅格地图生成

### 离线方式（推荐）

PCD → pcd2pgm → .pgm + .yaml：

```sh
pcl_convert_pcd_ascii_binary input.pcd /tmp/uncompressed.pcd 0
python3 pcd2pgm_node.py /tmp/uncompressed.pcd output_prefix z_min z_max
```

最佳 Z 滤波参数 `-0.05 ~ 0.06`（雷达系，z=0 = 雷达高度 ≈ 18cm 离地）。

### 在线方式

slam_toolbox 边走边建图，Ctrl+C 前 `rosrun map_server map_saver -f my_map`。

详见 [怎么得到栅格地图.md](怎么得到栅格地图.md)。

## 7. 定位

| 模式 | 定位方式 | 初值 | 精度 | 推荐 |
|------|---------|:--:|------|:--:|
| **NDT** | 当前帧点云匹配预建 PCD，牛顿优化 | **自动** | 最高（3D 全量） | ⭐ |
| slam_toolbox | 加载 .posegraph + .pgm，Karto 扫描匹配 | 自动 | 中（2D 降级） | |
| AMCL | 粒子滤波匹配 PGM | **手动 2D Pose** | 低（2D 降级） | |
| 边建图边导航 | slam_toolbox mapping 模式 | 自动 | 中 | |

NDT 是首选：自动初始化、3D 匹配精度远超 AMCL/slam_toolbox，`map → odom → livox_frame → base_link` 链路跟 AMCL 完全一致，move_base 无感切换。

## 8. move_base + TEB

### 关键配置

| 参数 | 值 | 原因 |
|------|-----|------|
| `max_samples` | 50 | Jetson 性能，7.9Hz |
| `include_costmap_obstacles` | false | 减少计算量 |
| `feasibility_check_no_poses` | 0 | 跳过可行性检查 |
| `exact_arc_length` | false | 近似弧长 |
| `xy_goal_tolerance` | 0.25 | 防目标点振动 |
| `cmd_angle_instead_rotvel` | false | 用 ω 不用角度 |

配置：[teb_local_planner.yaml](../src/nav_bringup/config/teb_local_planner.yaml)

### costmap 注意

- SLAM 模式：`global_frame: odom`，不用 `static_layer`，用 `rolling_window`
- AMCL / NDT / slam_toolbox 定位模式：`global_frame: map`，加 `static_layer`

详见 [全局与局部规划器.md](全局与局部规划器.md)。

## 9. cmd_vel → 底盘控制

`cmd_vel_to_ackermann.py`：Twist → duty + servo position。

| 映射 | 公式 | 说明 |
|------|------|------|
| 速度→占空比 | `duty = abs(v)/max_vel * max_duty` | 线性映射，保底 min_duty=0.07 |
| ω→舵机 | `pos = 1500 - omega/max_omega * steer_gain` | 1500=中位，<1500=右转 |
| 转向补偿 | `duty += abs(omega)/max_omega * 0.10` | 转弯时补动力 |
| 安全停止 | timeout 1.0s 无 cmd_vel → duty=0 | 防止失控 |

底盘控制节点（500Hz，四轮异向模式）：接收 duty + position，串口发 MCU。

| `fastlio_icp_nav.launch` | ICP 定位导航 |

所有 launch 命令见 [mainuse.md](../mainuse.md)。
