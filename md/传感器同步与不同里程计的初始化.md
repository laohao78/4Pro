# 传感器同步与不同里程计的初始化

## Mid360（LiDAR + IMU）

**同源硬件时钟**，天然同步，不需要外部时间同步。

| 指标 | 值 |
|------|-----|
| 时钟源 | Mid360 内置硬件时钟 |
| LiDAR 频率 | ~10Hz |
| IMU 频率 | ~200Hz |
| LiDAR ↔ IMU 偏移 | ~160ms（帧头 vs 最新 IMU，逐点时间戳已对齐） |
| 配置 | `time_sync_en: false`，`time_offset_lidar_to_imu: 0.0` |

FAST_LIO 内部用 CustomMsg 的逐点时间戳 + IMU 时间戳做对齐，帧级偏移不影响精度。

## D435i（Camera + IMU）

**非同源时钟**，存在时间偏移需要标定或在线估计。

| 方案 | 处理方式 | 配置 |
|------|---------|------|
| **ORB-SLAM3** | librealsense2 SDK 直读硬件流，内部同步 | 自动 |
| **VINS-Fusion** | 在线估计 td（时间偏移） | `estimate_td: 1` |

VINS-Fusion 实测 td ≈ 0.04s（40ms），收敛后稳定在 0.040~0.042s。

## 对比

| | Mid360 | D435i |
|------|:--:|:--:|
| 时钟源 | 同源 | IMU + Camera 非同源 |
| 需要外部同步 | 否 | 否（在线估计） |
| 时间偏移 | ~0 | ~40ms |
| 逐点时间戳 | ✅ CustomMsg | ❌ |
| 对 SLAM 影响 | 无 | td 估计后正常 |

## 各里程计初始化对比

| 方案 | 需要运动？ | 初始化方式 | 时长 | 注意 |
|------|:--:|------|------|------|
| **FAST_LIO** | 否 | 静止 2-3 秒 IMU bias 收敛 | ~3s | 启动后原地不动即可 |
| **NDT** | 否 | 默认从 (0,0,0) 搜索，也可给 2D Pose 缩小范围 | 即开即用 | 自动收敛，给初值更快更稳 |
| **slam_toolbox** | 否 | 需手动 2D Pose Estimate | 手动 | 加载 posegraph 后需给初值 |
| **AMCL** | 否 | 需手动 2D Pose Estimate | 手动 | 粒子滤波需要初始位姿 |
| **ORB-SLAM3** | **是** | Stereo+IMU，平移+旋转即初始化 | 数秒 | 实测效果很好 |
| **VINS-Fusion** | **是** | IMU 预积分 + 视觉 SFM | 数秒 | 容易漂，静止 crash，不如 ORB-SLAM3 稳 |

**结论**：LiDAR 系（FAST_LIO/NDT/slam_toolbox）无需运动即可初始化。视觉系中 ORB-SLAM3 实测很好，VINS-Fusion 容易漂，已降级为备用。
