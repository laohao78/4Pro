# 踩坑记录

交流中反复卡住的点，记录避坑。

## 1. PCD 坐标系

**问题**：PCD 的 z=0 到底是什么？反复猜了多层。

**答案**：看代码，别猜。

```cpp
// FAST_LIO laserMapping.cpp
// PCD 保存: feats_undistort → RGBpointBodyToWorld → world 系
// world 系原点 = 第一帧 IMU/LiDAR 位置
// z=0 = LiDAR 高度 ≈ 18cm 离地
```

**教训**：直接读 PCD 数据，CloudCompare 一眼就能看出 z 分布。别根据逻辑推理。

## 2. 代价地图死活不显示

**症状**：`robot's start position is off the global costmap` / `sensor out of map bounds`

**原因排查顺序**：
1. TF 链断了（最常见）→ `rosrun tf tf_echo map base_link`
2. `static_layer` 和 `rolling_window=true` 冲突 → 删 static_layer
3. `global_frame: map` 但 map 帧还没发布 → 改成 `odom`
4. `robot_base_frame` 不存在 → 确认 TF tree

**教训**：代价地图出问题先查 TF，再查参数冲突。别换规划器。

## 3. 规划器来回切换

详见 [全局与局部规划器.md](全局与局部规划器.md)。最终方案：TEB `max_samples: 50` + `include_costmap_obstacles: false`，Jetson 上 7.9Hz。

**教训**：先在终端看 `rostopic hz /cmd_vel`，确定是性能问题还是配置问题再动手换。

## 4. 底盘不动

**排查链条**：

```
/cmd_vel 有数据?
  → 没有: move_base 没规划
  → 有: 查 /motor_write_duty 有数据?
      → 没有: cmd_vel_converter 没收到/没发
          → 检查 timeout timer 是否覆盖了值
      → 有: chassis_control 串口发出去没?
          → receive_data() 阻塞 → 改成非阻塞
          → 串口权限: sudo chmod 666 /dev/ttyTHS0
          → duty 太小: 保底 min_duty=0.05
```

**教训**：从下往上逐级排查，别跳过。

## 5. TF 架构

**最终方案**：直接改 FAST_LIO 源码，不要转发。

```cpp
// laserMapping.cpp — 改两个字符串
"camera_init" → "odom"
"body"       → "livox_frame"
```

**曾经的弯路**（TF v3，已废弃）：tf_relay 转发 → 同名冲突 → body→base_link 和 livox_frame→base_link 重复父节点。

**教训**：少一层转发就少一层坑。静态 TF 用 `tf` 包的 publisher 发到 `/tf`，别用 `tf2_ros` 发 `/tf_static`（老节点可能看不到）。

## 6. 编译依赖

**FAST_LIO 适配 livox_ros_driver2**：
- `package.xml`: `<build_depend>livox_ros_driver</build_depend>` → `livox_ros_driver2`
- `CMakeLists.txt`: `find_package(livox_ros_driver ...)` → `livox_ros_driver2`
- 源码 `#include <livox_ros_driver/CustomMsg.h>` → `<livox_ros_driver2/...>`
- 源码 `livox_ros_driver::CustomMsg` → `livox_ros_driver2::CustomMsg`
- `git submodule update --init` 拉 ikd-Tree

## 7. 舵机方向

**最终值**：`position = 1500 - omega/max_omega * steer_gain`

- omega>0（ROS 逆时针=左转）→ position<1500 → 实际左转
- 经过三次正负号反转才定下来

**教训**：用 test_control 脚本直接发 `/cmd_vel` 验证，不要通过导航间接测。

## 8. 速度-占空比映射

**问题**：`_vel2duty` 公式太保守（0.5m/s → 0.08 duty），车不动。

**解决**：线性映射 `duty = v/max_vel * max_duty`，保底 0.05。
转向补偿：`duty += |omega|/max_omega * 0.10`。
