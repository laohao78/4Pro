# 标定、同步、初始化

---

## 一、标定：哪些需要，哪些不需要

| 标定内容 | Mid360 | D435i | 说明 |
|---------|:--:|:--:|------|
| LiDAR 内参 | ✅ 出厂 | — | 硬件固定，每台一样 |
| IMU 内参（bias/scale） | ✅ 出厂 | ✅ 出厂 | bias 运行时仍会在线估计 |
| LiDAR ↔ IMU 外参 | ✅ 出厂 | — | Livox 官方通用值 |
| Camera ↔ IMU 外参 | — | ✅ 出厂可作初值 | VINS/ORB 可在线微调 |
| LiDAR ↔ Camera 外参 | — | ✅ **FAST-Calib** | 0.5x 标定板，3 场景联合 RMSE 6.7mm |

### 各方案标定需求

| 方案 | 需要标定？ | 原因 |
|------|:--:|------|
| **FAST_LIO** | 否 | Mid360 LiDAR-IMU 同壳体，出厂完成。`extrinsic_T: [-0.011, -0.02329, 0.04412]` = 官方推荐值。直接法点云配准，外参差几毫米不影响 |
| **ORB-SLAM3** | 否 | D435i 固件存了真值（内参+外参），SDK 运行时读取。Stereo 自带尺度，IMU 仅辅助，ORB 特征匹配是主导 |
| **VINS-Fusion** | **是** | 已标：IMU 噪声(imu_utils) + 外参(固件) + 内参(固件 fx/cx/cy)。仍不如 ORB-SLAM3 稳，单目紧耦合本质对参数敏感 |
| **NDT/ICP/AMCL** | 否 | 纯 LiDAR 或 2D 激光匹配，不涉及 IMU 或相机 |

## 二、同步：每个传感器怎么对齐时间

### Mid360 — 同源硬件时钟

LiDAR 和 IMU 共板，同一硬件时钟，**天然同步**。

| 指标 | 值 |
|------|-----|
| 时钟源 | Mid360 内置硬件时钟 |
| LiDAR 频率 | ~10Hz |
| IMU 频率 | ~200Hz |
| 帧级偏移 | ~160ms（帧头 vs 最新 IMU 消息） |
| 逐点对齐 | ✅ CustomMsg 每点带时间戳 |
| 配置 | `time_sync_en: false`，`time_offset_lidar_to_imu: 0.0` |

### D435i — 两种方式

| 方案 | 同步方式 | 配置 |
|------|---------|------|
| **ORB-SLAM3** | SDK 直读硬件流，frameset 自带同步 | 无需配置 |
| **VINS-Fusion** | ROS topic 异步，在线估计 td | `estimate_td: 1` |

VINS 实测 td ≈ 0.040~0.042s（40ms）。

### 对比

| | Mid360 | D435i (ORB) | D435i (VINS) |
|------|:--:|:--:|:--:|
| 时钟源 | 同源 | SDK 硬件同步 | ROS topic 异步 |
| 需要外部同步 | 否 | 否 | 否（在线 td） |
| 时间偏移 | ~0 | ~0 | ~40ms |
| 逐点时间戳 | ✅ CustomMsg | ❌ | ❌ |

## 三、初始化：各方案怎么启动

| 方案 | 需要运动？ | 初始化方式 | 时长 | 注意 |
|------|:--:|------|------|------|
| **FAST_LIO** | 否 | 静止 2-3s，IMU bias 收敛 | ~3s | 启动后原地不动 |
| **NDT** | 否 | 牛顿法从 (0,0,0) 搜，可给 2D Pose 加速 | 即开即用 | 自动收敛 |
| **ICP** | 否 | 多假设网格搜（±2m/360°），也可给 2D Pose | 手动 | 点面法向量 |
| **slam_toolbox** | 否 | 加载 posegraph，需 2D Pose Estimate | 手动 | 需先 mapping |
| **AMCL** | 否 | 粒子滤波，需 2D Pose Estimate | 手动 | 2D 降级 |
| **ORB-SLAM3** | **是** | Stereo+IMU SFM，**画 8 字** | 数秒 | ORB 抗大运动，多大多快都行 |
| **VINS-Fusion** | **是** | IMU 预积分 + 视觉 SFM | 数秒 | **不能太剧烈**：KLT 光流帧间位移大就丢，平缓平移+慢转即可 |

**结论**：LiDAR 系无需运动即可初始化；视觉系需运动激励，ORB-SLAM3 稳定，VINS-Fusion 仅供备用。
