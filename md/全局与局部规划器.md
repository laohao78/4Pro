# 全局规划器 vs 局部规划器

move_base 里两者的分工：

| | 全局规划 (Global Planner) | 局部规划 (Local Planner) |
|---|---|---|
| **包** | `global_planner` | `teb_local_planner` |
| **算法** | A* / Dijkstra | TEB (Timed Elastic Band) |
| **坐标系** | `/map` | `/odom` |
| **代价地图** | `global_costmap` | `local_costmap` |
| **地图来源** | map_server 静态 .pgm | 传感器实时生成 |
| **范围** | 整个地图（固定） | 机器人周围（滑动窗口） |
| **更新频率** | ~1 Hz | ~5 Hz |
| **做的事** | 在已知地图上算最短路径 | 沿全局路径走，实时避障+轨迹优化 |
| **输出** | `/plan` (Path) | `/cmd_vel` (Twist) |

## 类比

- **全局规划** = 开车前看导航规划全程路线
- **局部规划** = 司机看前方 10 米路况，随时避让、微调

## 坐标关系

```
│   │  global_planner 在上面搜路    │        │
│   │                              │        │

│   │   │ │       机器人         │ │        │
│   │   │ └─────────────────────┘ │        │
│   │   └─────────────────────────┘        │
│   └──────────────────────────────────────┘
└───────────────────────────────────────────┘
```

## Jetson 性能实测

| 规划器 | Jetson 表现 | 结论 |
|--------|------------|------|
| TEB (默认参数) | 一次优化 11 秒 | ❌ 不可用 |
| TEB (`max_samples: 100`) | ~5Hz | ⭐ 可用 |
| DWA | 10Hz | ✅ 快但评分不直观 |
| DWB | 不兼容 ROS1 Noetic | ❌ |
| TrajectoryPlanner | ~10Hz | ✅ 最轻量 |

当前方案：TEB 差速模式 + `max_samples: 100` + `cmd_angle_instead_rotvel: false`。
转向通过 `cmd_vel_to_ackermann.py` 的 ω → servo position 实现，不在 TEB 层做 Ackermann 约束。
