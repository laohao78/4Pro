## xfer_format 格式控制

`xfer_format` 决定雷达发布的消息类型，在 launch 文件里设置：

```
msg_MID360.launch   →  xfer_format = 1  (CustomMsg)
rviz_mixed.launch   →  xfer_format = 0  (PointCloud2)
```

### 取值对照

| xfer_format | 枚举常量 | 消息类型 | Topic | 适用场景 |
|---|---|---|---|---|
| **0** | `kPointCloud2Msg` | `sensor_msgs/PointCloud2` | `/livox/lidar` | Rviz可视化、costmap、通用点云处理 |
| **1** | `kLivoxCustomMsg` | `livox_ros_driver2/CustomMsg` | `/livox/lidar` | **FAST_LIO 专用**（含逐点时间戳/tag/线号） |
| **2** | `kPclPxyziMsg` | `pcl::PointCloud<PointXYZI>` | `/livox/lidar` | PCL 直接使用 |
| **3** | `kLivoxImuMsg` | `sensor_msgs/Imu` | `/livox/imu` | 仅 IMU（不常见） |
| **4** | `kAllMsg` | 同时发上述所有 | 多 topic | ❌ **ROS1 不支持**，ROS2 专有 |

### ROS1 vs ROS2 差异

```
ROS1 驱动 (lddc.h)           ROS2 驱动 (pb_rm_simulation)
─────────────────────        ─────────────────────────────
kPointCloud2Msg = 0          kPointCloud2Msg = 0
kLivoxCustomMsg = 1          kLivoxCustomMsg = 1
kPclPxyziMsg    = 2          kPclPxyziMsg    = 2
kLivoxImuMsg    = 3          kLivoxImuMsg    = 3
(没有第5个)                   kAllMsg         = 4  ← ROS2独有
```

### ROS1 实车如何同时拿到两种格式

```
当前: xfer_format=1 → 只发 CustomMsg → FAST_LIO

需要 PointCloud2 给导航? 
→ FAST_LIO 输出 /cloud_registered_body (PointCloud2)
→ 不需要改驱动
```

## 启动雷达

```sh
cd /home/orin/Desktop/00/FAST_LIO
source devel/setup.bash

# FAST_LIO 用 (xfer_format=1, CustomMsg)
roslaunch livox_ros_driver2 msg_MID360.launch

# Rviz 可视化用 (xfer_format=0, PointCloud2)
roslaunch livox_ros_driver2 rviz_MID360.launch xfer_format:=0
```
