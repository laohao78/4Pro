# 怎么得到栅格地图

## 最终方案：pcd2pgm 离线转换

基于 [LihanChen2004/pcd2pgm](https://github.com/LihanChen2004/pcd2pgm) 的算法：
1. `pcl::io::loadPCDFile` 读 PCD
2. `PassThrough` Z 轴滤波
3. `RadiusOutlier` 去噪
4. XY 平面投影 → OccupancyGrid
5. 保存 `.pgm` + `.yaml`

### 使用

```sh
# 1. PCD 格式转换（binary_compressed → binary，不需要额外依赖）
pcl_convert_pcd_ascii_binary input.pcd /tmp/uncompressed.pcd 0

# 2. 投影为栅格
python3 /home/orin/Desktop/00/FAST_LIO/src/nav_bringup/scripts/pcd2pgm_node.py \
  /tmp/uncompressed.pcd \
  output_prefix \
  z_min z_max
```

### 实际运行

```sh
python3 pcd2pgm_node.py /tmp/scans_uncompressed.pcd sand_table -0.05 0.06
# 输出:
#   sand_table.pgm   — 511x215, 0.02m/pixel, 10.2m x 4.3m
#   sand_table.yaml  — 分辨率+原点+阈值
```

### 高度参数 z_min/z_max

在点云的体坐标系（livox_frame）下过滤：
- `z_min: -0.05` — 地面以下 2cm
- `z_max: 0.06` — 围栏顶部以上 1cm（围栏 ~8cm 高）

只保留道路两侧围栏所在的薄层，过滤屋顶/隧道等高层结构。

## 备选方案：slam_toolbox 在线建图

适合没有预先配准 PCD 的场景：

```
Mid360 → FAST_LIO → /cloud_registered_body
                         │
                         ▼
                pointcloud_to_laserscan → /scan
                         │
                         ▼
                    slam_toolbox → .pgm + .yaml
```

```sh
roslaunch nav_bringup fastlio_slamtoolbox_nav.launch
# 走一圈后
rosrun map_server map_saver -f my_map
```

## 输出文件

- `.pgm` — 灰度栅格图（黑=占据, 白=空）
- `.yaml` — 分辨率+原点+阈值参数

## 后续导航使用

```
map_server 加载 .pgm → global_costmap → global_planner → move_base
```
